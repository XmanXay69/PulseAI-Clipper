## Rules stated
- Goal: turn a finished Twitch stream into a YouTube post, with "no software whatsoever": use Twitch's browser tool [said 00:00].
- Twitch only saves a VOD if "store past broadcasts" is on; it is kept up to 7 days, while a published Highlight stays until deleted [said 01:01-01:21, 06:50]. Old streams cannot be recovered by turning the setting on later [said 01:21].
- Workflow in the Highlighter: pick the stream, press Highlight, the gold bar is what will be saved; drag the left handle to where the game starts to drop the "just chatting" part at the start [said 02:43-03:47]. Zoom the timeline with the magnifier to place the handle precisely [said 03:25].
- To cut a section out of the middle (his examples: a bathroom break and a spicy jelly-bean challenge he did not want on YouTube), park the playhead, press the scissors icon to split into two gold bars, then drag the edges so a gap is left; the gap is not in the final video, which is still one video [said 03:47-04:48].
- Find where the game changes and end the highlight there, so each highlight is one game; title it after the game and set the category to match [said 05:08-05:49].
- Publishing a long stream takes time to process; he jokes you may go and scroll for "an hour and a half" for a 4-hour source [said 06:10-06:30]; add thumbnail and metadata while it processes [said 06:30].
- Export straight to YouTube needs the accounts connected and the YouTube channel verified, or YouTube forces 15-minute segments [said 07:52-08:33]. Set visibility private first because YouTube shows 360p until it finishes the 1080p/720p processing [said 08:33-08:54].
- Collections work as playlists for highlights [said 09:15].
