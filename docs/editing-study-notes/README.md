# Evidence notes for the editing study

One file per video watched for [EDITING-STUDY-FINDINGS.md](../EDITING-STUDY-FINDINGS.md), named by the short name
that page uses (so `[Neistat 04:57]` there means `Neistat.md` here, at 04:57). They are the working notes the
findings were written from: what each tutor says, what their own timeline shows, how the video itself is
edited (including two measured cut rates), and how it compares with the playbook of the time.

How far to trust them:

- They were written by helper sessions following one brief, from frames and captions. Nobody listened to the
  audio, so "heard" means a caption. Timestamps can sit up to about 15 s from the time given.
- Only a few claims were re-checked against the source (see "How it was done" in the findings page). Where a
  helper's closing summary and its note disagreed, the findings follow the note.
- Cut rates use ffmpeg's scene filter at 0.35 and are floors; the notes say what each stretch contained.
- Sponsored or promotional segments are noted in each file and are not evidence.
- The notes were written against the playbook as it stood before 14 November 2026, so their "Against today's
  playbook" sections quote the old numbers. What moved is in the findings page.
