# Changelog

Release notes live in [`versions/`](versions/README.md), one folder per version:

- [1.6.0](versions/1.6.0/NOTES.md) — studio UI + instant replays + the first roadmap batches (word-safe cuts, intro/outro
  trimming, tighten, dead-air picker, music per chapter, own memes, looks, freeze frame, nudge, markers list, typed
  timecode, export sidecars + verification, Quick Export, search actions, J/K rating, fuzz-tested timeline).
- [1.5.0](versions/1.5.0/NOTES.md) (folded into 1.6.0) — studio UI (gradients, elevation, grouped sidebar, breadcrumb, pill page bar, richer
  timeline); ships with 1.4.0's features; 500-item roadmap.
- [1.4.0](versions/1.4.0/NOTES.md) (folded into 1.5.0) — instant replays (ask-first), slow push-ins, B-roll replaces memes on a shared beat,
  continuous beat-synced music, approve-the-cut analyzes first.
- [1.3.0](versions/1.3.0/NOTES.md) — ask-first extras (facecam punch-ins, B-roll, beat sync, speaker-aware cuts, approve
  the cut, title cards, export loudness check), editor-grade Edit My VOD (polish passes + automatic edit check),
  smooth timeline.
- [1.2.0](versions/1.2.0/NOTES.md) — Creative Commons music from YouTube, calmer quieter music, outlined captions, gameplay moments, live leveling %.
- [1.1.2](versions/1.1.2/NOTES.md) — playable while audio levels (with a % bar), faster leveling, updates appear right away.
- [1.1.1](versions/1.1.1/NOTES.md) — edits appear in the viewer instantly; update from inside the app.
- [1.1.0](versions/1.1.0/NOTES.md) — Edit Like a Reference, taste learning, chat replay signal, storyboard, overnight batch, brand kit,
  analytics calibration, Thumbnail Studio tie-in, resume after quitting, Report a Problem.
- [1.0.1](versions/1.0.1/NOTES.md) — polish: plain-language status, YouTube export preset, TikTok Native template.
- [1.0.0](versions/1.0.0/NOTES.md) — Edit My VOD (10–20 min YouTube edits), edit coach with performance score,
  TikTok Sans captions, analysis time estimates, pro-editor layout.
- [0.1.0](versions/0.1.0/NOTES.md) — preview builds.
